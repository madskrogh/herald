# Plain SQL with sqlc instead of an ORM

Database access is hand-written SQL, compiled into type-safe Go by sqlc and run through pgx. The core of Herald is Postgres-specific (`FOR UPDATE SKIP LOCKED` work claiming, partial indexes, `ON CONFLICT DO NOTHING` for idempotency), and those queries should be visible and reviewable as SQL, not generated by an ORM. sqlc checks queries against the schema when it generates code, so mistakes surface before runtime.
